# BatteryGuard Vision — Evaluation Guide

## Purpose

This guide describes how to evaluate BatteryGuard Vision v4.1 across different battery conditions, assess its visual findings, and document known limitations.

The objective is to evaluate the application's ability to identify potential visual abnormalities without making unsupported battery safety claims.

## Running the Tests

Run automated tests:

```bash
python -m pytest -q
```

Launch the application:

```bash
python -m streamlit run app.py --server.port 8502
```

Select **AWS Lambda + Bedrock Vision (experimental)**.

## Suggested Evaluation Scenarios

Use battery photographs that were not used during development or prompt refinement.

| Test category | Suggested images |
|---|---|
| Visible leakage or corrosion-like deposits | 2 |
| Visually normal batteries with labels or insulation | 2 |
| Possible swelling or deformation | 2 |
| Blurry or low-resolution photograph | 1 |

## Evaluation Criteria

For each image, record:

- The visually observable condition based on human review.
- The application's reported category and supporting description.
- Whether the highlighted regions correspond to meaningful visual features.
- Any false positives or missed abnormalities.
- Whether image-quality warnings are appropriate.
- Whether suggested follow-up actions are safe and reasonable.

## Important Limitations

OpenCV 5 bounding boxes represent candidate visual irregularities. They are not defect-specific annotations generated by Amazon Bedrock.

Amazon Bedrock Nova Lite provides independent contextual interpretation but may incorrectly identify or overlook abnormalities.

The prototype has not established quantitative detection accuracy on a representative labeled dataset.

Photographs alone cannot reliably confirm battery chemistry, hidden damage, thermal hazards, or overall battery safety.

## Evaluation Principles

- Do not modify detection thresholds or prompts based on individual evaluation images.
- Record both successful findings and failure cases.
- Do not describe possible abnormalities as confirmed defects.
- Avoid unsafe instructions to physically manipulate potentially damaged batteries.
- Report observed results without extrapolating to untested battery conditions.

BatteryGuard Vision is an experimental visual triage application intended to assist human inspection, not replace professional safety assessment.
